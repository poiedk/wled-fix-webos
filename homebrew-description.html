WLED Fix

One-click WLED rediscovery and Hyperion repair for rooted LG webOS TVs.

v1.1.2 adds a TV-native remote-first interface, Simple and Advanced Settings, fast discovery, Hyperion verification, optional LED test, backup retention, technical details, and BACK-only navigation with a dedicated Exit App action.

  • Fast check of the current Hyperion target before full subnet scan
  • ARP-assisted discovery
  • Automatic Hyperion host/hostList update
  • Optional Hyperion restart and LEDDEVICE verification
  • Configurable scan timeout, interface, instance, backups, and verbose logging

Requires root, Homebrew Channel, Hyperion.NG and WLED on the same IPv4 /24 network.
